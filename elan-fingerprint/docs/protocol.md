# Протокол USB ELAN (image-сенсоры, драйвер libfprint `elan`)

Источник: `libfprint/drivers/elan.h`, `elan.c`, upstream commit `6f9479c3` (2026-09-02, v1.94.100).
Протокол восстановлен разработчиками libfprint по USB-дампам Windows-драйвера.

## Транспорт

| Endpoint | Направление | Назначение |
|---|---|---|
| `0x01` | OUT (bulk) | команды, 2 байта |
| `0x83` | IN (bulk) | ответы на команды |
| `0x82` | IN (bulk) | кадры изображения |

Интерфейс: класс `0xff` (vendor-specific). Таймаут команды: 10000 мс.

## Команды

| Байты | Ответ (байт) | EP | Назначение |
|---|---|---|---|
| `40 19` | 2 | 0x83 | версия прошивки |
| `00 0c` | 4 | 0x83 | размер сенсора (ширина/высота) |
| `40 2a` | 2 | 0x83 | активация (только 0907) |
| `40 31` | — | — | включить подсветку/сканирование |
| `40 3f` | 1 | 0x83 | ожидание пальца (ответ приходит при касании) |
| `00 09` | W×H×2 | 0x82 | чтение кадра, 16 бит на пиксель |
| `40 13` | 1 | 0x83 | статус сенсора |
| `40 23` | 1 | 0x83 | статус калибровки |
| `40 24` | 2 | 0x83 | среднее значение калибровки |
| `00 0b` | — | — | стоп, LED off |

## Последовательность

1. Активация: `40 19` → `00 0c` → (0907: `40 2a`).
2. Калибровка (FW ≥ 0x0138): кадр фона `00 09` → `40 24` → при отклонении > 500 повтор `40 23` до готовности (10 попыток, 0C58: 30).
3. Захват: `40 31` → `40 3f` (блокирующее ожидание) → цикл `00 09` до 7–30 кадров, пока палец на сенсоре (проверка с таймаутом 200 мс).
4. Обработка на хосте: вычитание фона, нормализация, обрезка кадров до 50 строк, отброс 2 последних кадров, сшивка (swipe-сенсор), поворот (кроме 0C03).
5. Сопоставление: NBIS minutiae + bozorth3, порог `bz3_threshold = 24`.
6. Стоп: `00 0b`.

## Варианты устройств ELAN 04f3

| Семейство | Драйвер | Признак |
|---|---|---|
| Image USB (0903, 0c01–0c33, 0c3d, 0c42, 0c4b, 0c4d, 0c4f, 0c58, 0c63, 0c6e) | `elan` | шаблон хранится на хосте |
| Match-on-chip USB (0c7d … 0cb6) | `elanmoc` | шаблон в сенсоре, другой набор команд |
| SPI + HID (ACPI `ELAN7001`) | `elanspi` | не USB; виден в `/sys/bus/spi` |
