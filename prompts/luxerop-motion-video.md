# LUXEROP — промпт для Claude Code: motion-видео для TikTok (9:16, до 60 с)

```xml
<role>
Ты — senior motion designer и инженер видеопайплайнов (Python + FFmpeg).
Делаешь премиальные бренд-ролики уровня студийного шоурила полностью кодом:
процедурная графика, кинетическая типографика, синхронизация с битом.
</role>

<context>
Бренд: LUXEROP — услуги по рекламе, монтажу, анимации и видеопродакшену.
Цель ролика: показать «перформанс» — визуальный уровень автора — и привести к заявке.
Площадка: TikTok / Reels / Shorts. Зритель решает за 1–2 секунды, смотреть или листать.
Стиль: dark luxury. Чёрный фон, золото, неоновый акцент, глубина, свечение, скорость.
</context>

<task>
Сгенерируй ОДИН готовый файл `out/luxerop_tiktok.mp4` длительностью ровно 50 секунд:
40 секунд перформанс-анимации + 10 секунд финального экрана с контактами.
Вся графика и звук создаются процедурно. Внешние видео, стоки и чужая музыка запрещены.
</task>

<tech_spec>
- Разрешение: 1080x1920 (9:16), 60 fps, progressive.
- Кодек: H.264 High, yuv420p, CRF 16, preset slow, `-movflags +faststart`.
- Звук: AAC 48 kHz, 192 kbps, stereo, громкость -14 LUFS (`loudnorm`), true peak ≤ -1 dBTP.
- Длительность: 50.0 с (допуск ±0.05 с). Проверка через `ffprobe`.
- Темп: 120 BPM → 1 бит = 0.5 с, 1 такт = 2 с. Все склейки, вспышки и появления текста — строго на долях бита.
- Инструменты: Python 3 (numpy, Pillow, при необходимости moderngl/pycairo), FFmpeg.
  Кадры передаются в FFmpeg через pipe (rawvideo rgb24), без сохранения тысяч PNG на диск.
- Детерминизм: фиксированный seed для всех случайных величин.
- Шрифт: Unbounded или Montserrat (с кириллицей). Скачай с Google Fonts в `assets/fonts/`.
  Если сеть недоступна — используй системный шрифт с кириллицей и сообщи об этом.
</tech_spec>

<palette>
- Фон: #050505 → #0B0B12 (глубокий градиент, лёгкая виньетка).
- Основной: золото #D4AF37, блик #FFF1C1.
- Акцент: электрический фиолетовый #7B2CFF и циан #00E5FF (только на пиках).
- Текст: #FFFFFF, вторичный #BFBFBF.
</palette>

<storyboard>
Тайм-коды жёсткие. Каждая сцена — отдельная функция `scene_xx(t, frame)`.

1. 00.0–03.0 HOOK
   Полная тьма → на первом бите из центра взрыв ~3000 золотых частиц.
   Частицы разлетаются с motion blur, оставляют световые следы. На 2.5 с — белая вспышка.
2. 03.0–10.0 LOGO REVEAL
   Частицы собираются в слово LUXEROP (частицы летят к точкам контура букв).
   Затем буквы «запекаются»: bloom-свечение, золотой блик проходит слева направо,
   лёгкая хроматическая аберрация (RGB-сдвиг 2–4 px) на ударах бочки.
3. 10.0–18.0 LIQUID FLOW
   Логотип растворяется в жидкий градиент (domain-warped noise) золото→фиолет.
   Камера медленно приближается (scale 1.0→1.15, ease-in-out).
4. 18.0–28.0 KINETIC TYPE
   Слова сменяются на каждый бит, крупно, на всю ширину:
   «РЕКЛАМА» → «МОНТАЖ» → «АНИМАЦИЯ» → «ВИДЕО» → «MOTION» → «ВИЗУАЛ» → «ЭМОЦИЯ» → «LUXEROP».
   Приёмы: scale-punch (1.3→1.0 за 0.15 с), маска-шторка, smear, глитч-слайсы на каждом 4-м бите.
5. 28.0–36.0 HYPER TUNNEL
   Псевдо-3D тоннель из золотых колец/сетки, ускорение (speed ramp), стробы на сильных долях.
   Внутри тоннеля мелькают геометрические фигуры, параллакс в 3 слоя.
6. 36.0–40.0 FINAL HIT
   Резкая остановка → тишина 0.5 с → удар → логотип LUXEROP крупно с shockwave-кольцом
   и разлётом искр. Это кульминация ролика.
7. 40.0–50.0 CTA (10 секунд)
   Спокойный фон: медленно дрейфующие золотые частицы, мягкое свечение.
   Тексты появляются по очереди (fade + slide-up 40 px, ease-out, шаг 0.5 с):
     Строка 1: «Хотите заказать рекламу,»
     Строка 2: «красивый монтаж,»
     Строка 3: «анимацию или видео?»
     Строка 4 (крупнее, золото): «Обращайтесь ко мне»
     Блок контактов (с простыми векторными иконками, нарисованными кодом):
       Telegram  @luxerop
       Instagram @ryskeldyaslan
   С 45.0 с контакты слегка «дышат» (scale 1.00↔1.03, период 2 с), чтобы удерживать взгляд.
   Последние 0.5 с — плавное затухание в чёрный.
</storyboard>

<audio>
Синтезируй трек кодом (numpy → WAV → FFmpeg), 120 BPM, 50 с:
- Kick: синус 150→45 Гц с экспоненциальным спадом, на каждую долю с 3.0 с.
- Sub-bass: 55 Гц, сайдчейн от кика.
- Hi-hat: высокочастотный шум 30 мс на слабых долях.
- Riser: шумовой подъём с фильтром на 26–28 с и 34–36 с.
- Impact: низкий удар + реверберация на 36.5 с.
- 00.0–03.0: только нарастающий гул; 40–50 с: мягкий пэд-аккорд без ударных.
Каждое визуальное событие из storyboard совпадает с аудио-событием (±1 кадр).
</audio>

<constraints>

  НЕ правее 940 px (правая колонка кнопок). Все контакты — по центру внутри этой зоны.
- Текст CTA читается минимум 1.5 с после появления. Размер шрифта контактов ≥ 64 px.
- Никаких дефолтных шрифтов без кириллицы: «квадратики» вместо букв = провал.
- Без мерцания и banding: добавь лёгкое film grain (2–3%) и дизеринг градиентов.
- Никаких placeholder'ов, TODO и «упрощённых версий». Делай полный результат.
- Не спрашивай подтверждений по ходу работы. Принимай решения сам и фиксируй их в README.
</constraints>

- `ffmpeg -i out/luxerop_tiktok.mp4 -af ebur128 -f null -` (итоговый Integrated ≈ -14 LUFS)
```
